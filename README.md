# ecp

Настольное приложение для выработки и проверки электронной цифровой подписи (ЭЦП) по белорусскому стандарту **СТБ 34.101.45-2013**.

Криптографическое ядро написано на Rust, прикладная логика и графический интерфейс - на Python (PySide6). Платформа: Windows 11 (основная), Linux.

## Что делает программа

- **Генерация ключей** - выработка личного и открытого ключей bign (кривая bign256).
- **Подпись файлов** - выработка ЭЦП по СТБ 34.101.45-2013 (хэширование belt-hash, подпись bign).
- **Проверка подписи** - проверка ЭЦП по файлу, открытому ключу или сертификату.
- **Сертификаты X.509** - выпуск и разбор сертификатов открытых ключей (ASN.1 DER).
- **Расширенная подпись CAdES** - форматы CAdES-B-B и CAdES-B-T (с метками времени).
- **Штампы времени** - запросы и проверка ответов службы штампов времени; есть локальная служба для работы без внешнего сервера.
- **Журнал событий** - запись и анализ событий безопасности.
- **Аутентификация пользователей** - вход по логину и паролю, привязка к устройству, токены сессии.
- **Самотестирование и контроль целостности** - проверка корректности алгоритмов на тестовых векторах и подписанный манифест с хэшами файлов программы при каждом запуске.
- **Безопасное обновление ПО** - установка обновлений из локального подписанного пакета с проверкой подписи, хэшей, SBOM и откатом при ошибке.

## Стандарты и алгоритмы

| Область | Стандарт / алгоритм |
| --- | --- |
| Электронная цифровая подпись | СТБ 34.101.45-2013 (bign, кривая bign256) |
| Хэширование | СТБ 34.101.31 (belt-hash) |
| Блочное шифрование | СТБ 34.101.31 (belt-block) |
| Генерация псевдослучайных чисел | СТБ 34.101.47 (brng-ctr), HMAC на базе belt-hash (hmac-hbelt) |
| Штампы времени | СТБ 34.101.82 |
| Расширенная подпись | CAdES (ETSI EN 319 122), профили B-B и B-T |
| Сертификаты | X.509 (RFC 5280), кодирование ASN.1 DER (ITU-T X.690) |
| Хэширование паролей | PBKDF2-HMAC-SHA256 (RFC 8018) |
| Токены сессии | JWT, HS256 (RFC 7519) |
| Подпись пакетов обновления | Ed25519 (RFC 8032) |
| Описание состава ПО (SBOM) | CycloneDX 1.5 |

## Архитектура

- **Rust-ядро** (`src/lib.rs`) - belt-hash, hmac-hbelt, brng-ctr, работа с ключами, ЭЦП bign (п. 7.1.3-7.1.4 стандарта); подключается к Python через PyO3/Maturin.
- **Python-слой** (`python/ecp/`) - ASN.1, X.509, CAdES, штампы времени, конфигурация, журнал, аутентификация, обновление ПО.
- **Интерфейс** (`python/ecp/gui/`) - графическое приложение на PySide6.

## Технологии

Python 3, PySide6, Rust, PyO3, Maturin, `cryptography`, PyInstaller (сборка `.exe`).
